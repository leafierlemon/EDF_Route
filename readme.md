# EDF引き撃ちルートシミュレータ

EDFでの引き撃ちルートから、攻撃される量や維持できる距離を計算する。

- route.py
    周回安定後の効率の計算用

- routeplot.py
    周回が安定するまでの計算用
    動画生成可

## DEMO

![demo](./p1q2.mp4)

## Features

EDFでの引き撃ちルートから、攻撃される量や維持できる距離の計算をする  
敵の動きを単純化し、下記の想定をしている

- プレイヤーにまっすぐ近づく
- 固定距離に近づいたら移動を停止
- その移動停止分だけ攻撃する

## Requirement

- python3
  - argparse
  - matplotlib

## Usage

```bash
python ./route.py 1000 465 100 10
```

マップの広さ：1000×1000
角を円として回る際の半径：465
敵の攻撃開始距離：100
周回数：10

```bash
python ./routeplot.py p1q1.json -s
```

```json
{
    "map":[1000,1000],//マップの広さ[x,y]
    "ps":[//プレイヤーの設定
        {
            "R":465,//角を円として回る際の半径
            "area":0,//初期位置　0:左上の四半円 1:左の外周直線 2:左下の四半円 と、反時計回りに0から7
            "offset":0,//エリア内での初期位置　反時計回りに0以上
            "wait":0,//開始時の移動停止時間
            "v":1//移動の速さ
        }
    ],
    "qs":[//敵の設定
        {
            "xy":[600,1000],//初期位置[x,y]
            "v":1.0,//移動の速さ
            "r":100//攻撃開始距離　この距離で移動停止する。停止量に応じてスコアに加算する。
        }
    ],
    "time":{
        "ignore":4000,//移動はさせるが、スコア計算と描画では無視する時間
        "count":6000//移動、スコア計算、描画を行う時間
    },
    "video":{
        "speed":10//動画の再生速度
    }
}
```

## Note

速度マイナス（時計回り）には対応していない  
移動の途中で止まるなどにも対応していない
